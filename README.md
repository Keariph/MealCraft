### Monolith to Microservices Roadmap:
1. **Phase 1 (Current):** Monolithic backend handling all domains.
2. **Phase 2:** Database separation (splitting the monolithic DB into service-specific databases).
3. **Phase 3:** Extracting bounded contexts into independent microservices.
